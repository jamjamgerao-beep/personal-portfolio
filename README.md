## Features

- Green jade visual theme
- Responsive layout for desktop, tablet, and mobile
- Profile section
- Skills section
- Achievements section
- Projects section
- Contact section
- CSS-only hover effects and animations
- Your profile photo is already included as `profile.jpg`
- No JavaScript required

## Files

- `index.html` - Main webpage
- `style.css` - Complete design and responsive styling
- `profile.jpg` - Profile picture

## How to run

1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click `index.html`.
4. The portfolio will open in your browser.

## GitHub Pages

Upload all three files to your GitHub repository. Then enable GitHub Pages from:

Settings → Pages → Deploy from branch → main → root

Your portfolio can then be accessed through the GitHub Pages URL provided by GitHub.
